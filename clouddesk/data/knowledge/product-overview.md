# What Is CloudDesk?

CloudDesk is a B2B SaaS platform that lets engineering teams monitor, manage, and integrate
with their own downstream customers through a single API and web console. Every CloudDesk
organization gets a dashboard, a REST API, usage analytics, and an embedded AI support
assistant that can answer product questions and investigate account/billing issues on behalf
of the customer.

## Core building blocks

An **organization** is the top-level container for a company's CloudDesk account. Inside an
organization, individual **customers** (end users of the organization) have their own
**account** (login/security state), **subscription** (which plan they're on), **API keys**,
and **usage records**. This structure lets a single CloudDesk organization serve many
customers with independent billing and entitlements.

## Who CloudDesk is for

CloudDesk is built for teams that need to expose a metered, rate-limited API to their own
users without building billing, authentication, and usage-tracking infrastructure from
scratch. Typical CloudDesk customers are SaaS companies embedding CloudDesk's API behind
their own product, and internal platform teams standardizing on CloudDesk for usage-based
access control.

## Support model

Every plan includes support, but the level differs: Free customers get community support,
Pro and above get priority email support, and Enterprise customers get a dedicated support
contact. Regardless of plan, all customers can use the AI Support chat embedded in the
CloudDesk dashboard, which can look up real account/billing/technical state and, for
sensitive actions like refunds, create a request that a human reviews before it takes effect.
