# Production hardening follow-up (spec section 27's Phase 10 report gap, closed 2026-09-25):
# Postgres-backed LangGraph checkpointer so a paused/in-flight workflow thread survives a backend
# restart (previously `MemorySaver`, in-process only). Pinned to 3.1.2, the first release after
# CVE-2026-71433 (a namespace-prefix-matching information-disclosure issue in the Postgres/SQLite

# langgraph-checkpoint>=4.1,<5.0, satisfied by the langgraph-checkpoint 4.2.0 that langgraph==1.2.12
# already pulls in (no downgrade). Uses the `psycopg` (v3) driver, not `asyncpg` (SQLAlchemy's
# driver) — a separate connection pool against the same DATABASE_URL, not a second database.
